# 古建筑修复对照档案（Heritage Restore Archive）

在网页上编辑**照片对、阶段与结构锚点**；服务端为大图异步生成**瓦片金字塔**；数据库保存
**摄影条件、对齐变换与批准说明**。核心是一条不可退让的领域规则：

> **不同视点的照片，不能只拉到相同宽高就宣称可比。**
> 每次“对齐”都必须声明**配准模型**、给出**可量化的误差界限**；
> 不满足条件时强制**退回并排观察（side-by-side）**。
> 修复后的**新增构件只标记、不变形**，绝不扭曲成旧结构。

零第三方运行时依赖（仅用 Node 内置模块 + zlib），自带合成古建旧照/新照，可完全离线演示。

## 运行

```bash
node server/server.js           # 默认 http://localhost:8080
# 可选：限制单次解码像素预算（资源保护）
MAX_DECODE_PIXELS=4000000 node server/server.js
npm test                        # 20 项端到端集成测试（临时端口 8917）
```

打开页面后点「**载入演示工程**」。深链接形如：

```
#/pair/<id>/v/<n>?mode=slider|side&split=50&layer=old,new,added,notes
```

精确复现某一**已批准版本**的视图模式、滑杆位置与图层；查看历史版本时不会自动跳到最新。

## 配准模型与误差界限

| 级别 | 模型 | 最少点 | 何时可用 |
|---|---|---|---|
| M0 | 并排观察 | 0 | **缺基准点/共线/超误差界限时的强制回退** |
| M1 | 相似（旋转+缩放+平移） | 2 | 同机位、仅变焦/轻转 |
| M2 | 仿射（最小二乘） | 3 非共线 | 近似同一平面正立面 |
| M3 | 人工对应点 TPS 薄板样条 | 6 | 立面轻微起伏，需逐点贴合 |

判定（可在 `math.js register()` 配置）：

* 相对均方根 `relRms ≤ 0.5%` 且相对最大误差 `relMax ≤ 1.5%`；
* 残差**无空间聚集**（显著残差若聚在一隅，提示透视汇聚/结构差异，仿射不适用）；
* 变换只在**控制点凸包内**声明有效，凸包外标为外推区；
* 点数不足、点共线、解算奇异 → 一律 M0 并排。

**仿射 vs 人工对应点，在透视/遮挡/结构变化下的限制**（详见 `doc/design.md §2.4`）：

* *透视*：近大远小使单一全局仿射无法同时贴合近点远点，残差呈系统性、方向性分布；真透视需共面前提下的单应。
* *遮挡*：脚手架/树木处没有同源点，遮罩内的点不参与解算与误差，TPS 在遮挡处的外推不可作为依据。
* *结构变化*：新增斗拱/瓦面在旧照无对应结构，用「新增构件」遮罩标出并保持新照原生形状；
  比较结论只能写“旧照此处残损/缺失、新照为新增”，**不得**写“旧结构恢复为…”，也不得做形变。

## 坐标迁移（裁切/方向/翻转）

标注与锚点都存于**规范像坐标**。图片旋转(EXIF 1/3/6/8)或裁切后，
用明确的 `R = 旧规范帧 → 新规范帧` 矩阵迁移；迁出画面或矩阵不可逆 → 该标注置 **PENDING 待复核**。
**手工翻转**无法唯一确定左右关系时，不猜测——全部锚点与文字注释进入待复核，旧配准作废。

## 已覆盖的边界场景

| 场景 | 系统行为 |
|---|---|
| 验收一侧资源晚到 | pair=`INCOMPLETE`，可先加文字注释，禁止配准/批准；晚到后重走流程 |
| 授权过期 | 原图字节 `403` 占位；**已批准快照结论/注释/保留瓦片仍可访问** |
| 图像翻转 | 无法唯一复合 → 全部标注待复核 |
| 两编辑同改一锚点 | 锚点乐观锁，后到者 `409 ANCHOR_VERSION_CONFLICT` 并附服务器当前值，不静默覆盖 |
| 瓦片生成途中换图 | 逐瓦片检查 `pairVersion`，版本推进即任务 `SUPERSEDED`，旧瓦片不挂新版本 |
| 超大解码任务 | 解码前按 `MAX_DECODE_PIXELS` 预算拒绝（`REJECTED_RESOURCE_LIMIT`），并发/超时受控 |
| 已批准版本 | 内容冻结不可变（再编辑 `409`），后续修改另开版本，深链接永久复现 |
| 未开放区域说明 | `pinnedRestricted` 常驻独立面板，任何图层开关都不会令其消失 |

## 数据与持久化

演示用 JSON 文件库（`data/db.json`，写入带文件锁与原子 rename）。生产可将 `store.js`
替换为事务型数据库实现，接口与不变量不变。瓦片产物按 `pairVersion + 内容哈希`
存于 `data/tiles/`，版本不可变。
