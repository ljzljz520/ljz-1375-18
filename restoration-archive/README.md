# 古建筑修复对照档案

在浏览器中编辑**照片对、修复阶段与同名实物锚点**；服务端生成**大图瓦片（DZI）**；
数据库（SQLite）保存**摄影条件、对齐变换及批准说明**。照片修订不可变，提交后形成
带批准的**不可变版本**，访客凭深链接复现同一份比较。

## 运行

```bash
npm install
npm start            # http://localhost:3000
npm test             # 24 项域规则/集成/资源保护测试
# 环境变量：PORT、DATA_DIR、MAX_DECODE_PIXELS（默认 60,000,000）、TILE_CONCURRENCY（默认 1）
```

## 为什么不是“拉到相同宽高就可比”

不同视点的两张照片存在旋转、缩放、平移、轻微透视与遮挡。仅统一宽高只能对齐画布，
不能对齐**实物**。系统因此要求一个明确的**配准模型**和一个**误差界限**：

| 方式 | 数学含义 | 需要锚点 | 结果 | 视图 |
|---|---|---|---|---|
| **仿射配准** | 最小二乘 6 参数（旋转/缩放/平移/剪切），左→右 | ≥3 且不共线 | 逐点残差、RMSE、最大误差 | 最大误差 ≤ 界限且行列式为正（保向）才允许**滑块叠加**；否则**退回并排** |
| **人工对应点映射** | 不假设全局变换，对应点逐对成立 | ≥1 | 只有对应，没有连续映射 | **永远只并排联动 + 对应连线**，不产生滑块叠加 |
| 缺基准点 | — | 0 | `unavailable` | 并排观察 |

- 误差门限默认 3px，可在编辑台调整；`maxErrorPx`、`rmsePx`、`tolerancePx` 落库并写入版本清单。
- 仿射拟合要求**行列式为正**：拟合结果若包含镜像翻转（常见于未声明的图像翻转），拒绝叠加。
- **透视、遮挡、结构变化的限制**：仿射不能校正真正的透视（需要单应/更多自由度），
  遮挡区与新增结构没有真实对应。叠加只绘制在**两侧锚点凸包的交集有效域**内，域外不做外推；
  修缮后的**新增结构多边形**被从旧图叠加中挖除，新构件绝不会被旧影像扭曲覆盖。
  误差一旦越界，系统降级为并排——宁可不可叠加，也不伪造可比性。

## 坐标迁移：裁切 / 方向变化

- 旋转（90/180/270）、水平/垂直翻转、裁切都是**显式声明**的操作（见 `server/geometry.js`）。
  服务端用 sharp 执行像素变换，域层用同一矩阵把锚点、新增结构多边形顶点迁移到新修订坐标系。
- 迁移后越界的点无法可信落点 → `pending_review`（待复核）；
- **未声明的直接换片**（无法判断是否翻转、是否同视角）→ 该侧全部锚点进入待复核，
  旧配准变换标记 `stale`，新增结构多边形清空待重绘。
- 每个锚点带乐观锁版本号 `ver`：**两编辑同改一锚点**，后提交方收到 `409 ANCHOR_VERSION_CONFLICT`。

## 版本、批准与深链接

- 编辑作用于当前草稿；“提交版本”把全部照片修订（含 `sha256`、尺寸、摄影条件、授权）、
  锚点、配准结论、视图判定、新增结构、注释固化为不可变 manifest（`versions.manifest`）。
- 提交门阻止：一侧资源晚到（`SIDE_MISSING`）、授权过期（`LICENSE_EXPIRED`）、存在待复核锚点。
- **批准门**再次校验授权有效期；批准人及批准说明随版本保存。
- `/viewer.html#/v/<versionId>` 只读、按 manifest 固定的修订 ID 取瓦片/派生图与注释：
  **滑块、并排、文字注释引用同一照片组版本**，以后的编辑不会改变已批准比较。
- **未开放区域说明**是 `scope=persistent` 注释，与任何业务图层的可见性解耦，
  图层切换（修缮前/修缮后/锚点开关）不会使其消失。

## 服务端与资源保护

- 上传与任何解码前先读元数据：`width*height > MAX_DECODE_PIXELS` 直接返回 `422 IMAGE_TOO_LARGE`，
  不进入像素解码（`sharp({limitInputPixels})` 双保险）。
- 瓦片作业串行排队（`TILE_CONCURRENCY` 可调），DZI 256px 分块写入 `data/tiles/<revId>/`。
- **生成途中照片替换**：作业开始前与发布前各比对一次源文件 `sha256`，
  不一致即 `aborted_replaced`、删除临时目录、绝不发布；且瓦片按修订 ID 隔离，
  已批准版本固定旧修订，不会错挂到新照片。
- 编辑器使用 1600px 派生图（标注坐标按全分辨率换算）；比较视图在瓦片就绪后使用 DZI，缺块不阻塞。

## 目录

```
server/geometry.js  仿射最小二乘、误差界限、人工映射、凸包、显式几何迁移
server/image.js     上传探测、派生图、几何执行、DZI 瓦片队列与指纹复检
server/db.js        SQLite schema（摄影条件/授权/变换/锚点锁/版本/批准/瓦片作业）
server/store.js     业务规则（晚到挂接、待复核、配准门、提交/批准门、资源限制）
server/server.js    HTTP/API、multipart 上传、不可变瓦片与派生图静态服务
public/editor.html  编辑台；public/viewer.html 访客深链接；js/viewer.js DZI 渲染
test/               node --test：24 项（域几何、全流程集成、超大/换片保护）
```
